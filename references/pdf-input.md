# 生成中文 PDF

将已经核对的叙述、表格和图注写入临时 UTF-8 JSON。题名、摘要和各级标题只写文字，脚本排版时补上摘要标签和章节序号。`sections` 按阅读顺序排列，`level` 默认为 1；要在一章下分节，先给出该章，再连续写入 `level: 2` 的小节。`paragraphs`、`table`、`figure` 均可选。

题名为 22 磅宋体居中，一级标题为 16 磅楷体居中，二级标题为 10.5 磅黑体左齐。摘要采用 10.5 磅正文，固定行距 15 磅，“摘　要：”标签加粗并与内容同行。正文采用宋体和 Times New Roman，10.5 磅，两端对齐，首行缩进约 24 磅。

```json
{
  "title": "[研究主题] 实验进度报告",
  "period": "[材料覆盖的日期或批次]",
  "summary": "[本轮解决的问题与采取的改动]。[同条件下与基线相比的主要进展，以可核实的结果支撑]。[这一进展的价值与适用边界]。",
  "sections": [
    {
      "title": "[研究问题与方法选择]",
      "paragraphs": ["[背景、目标、原方法及选择依据]", "[观察到的局限与针对性的改动，引用 E1]"]
    },
    {
      "title": "对照实验结果"
    },
    {
      "level": 2,
      "title": "[本组对照回答的具体问题]",
      "paragraphs": ["[评估口径、指标方向、重复次数和未控制因素]"],
      "table": {
        "headers": ["方法 / 运行", "[指标及单位]", "与基线之差（本组减基线）", "证据"],
        "rows": [["[基线]", "[原值]", "基线", "E2"], ["[改进版本]", "[原值]", "[带单位的差值]", "E2"]]
      }
    },
    {
      "title": "[现有证据支持的决策与下一轮验证]",
      "paragraphs": ["[结果的价值、适用边界]", "[优先验证的问题、对照、指标及判断依据]"]
    },
    {
      "title": "证据出处",
      "paragraphs": ["实验根目录：[完整路径]", "E1　[记录路径、运行编号和定位]", "E2　[评估表路径、工作表和行列]"]
    }
  ]
}
```

使用图像时，在相应章节添加 `"figure": {"path": "figures/error.png", "caption": "图 1　[条件、观看要点及证据编号]"}`。使用可读的本地 PNG 或 JPEG；相对路径从 JSON 所在目录解析，也可使用绝对路径。表格过宽时，将不同指标分表或改为逐行展示。

## 引用外部文献

把文献按首次引用顺序放入顶层 `references` 数组。在对应句子里写 `[1]`、`[2]` 等，同一来源每次用同一编号。PDF 会将引文号排成深蓝下划线上标，链接至文末同号条目。“参考文献”为无章序号的左齐黑体标题；各条目采用悬挂缩进。

每个数组元素可直接写完整题录字符串，省去开头的编号。期刊文献保留作者、题名、`[J]`、刊名、年卷期及页码或文章号；会议论文用 `[C]`，网络资源用 `[EB/OL]`。有已核实的网址时，可用对象 `{"text": "完整题录", "title": "题录内的原题名", "url": "对应的网址"}`，使文末题名可点击。只引用实际用到的来源。只有实验记录时，省略 `references`，在“实验记录与数据出处”中列出 E1、E2 的定位信息。

## 渲染与检查

用已装 ReportLab 的 Python 运行；Codex 桌面端可通过 `load_workspace_dependencies` 定位内置 Python。以下路径按本机技能位置和本次输出位置替换。

```text
python "<技能目录>/scripts/render_report.py" "<临时目录>/report.json" "<输出目录>/实验进度报告.pdf"
```

需要指定中文字体时，追加 `--font "<中文字体路径.ttf>"`。完成后确认 PDF 能打开、中文可读，并核对跨页表头和证据出处。临时 JSON 可保留在临时目录。
